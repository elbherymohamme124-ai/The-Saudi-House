# البيت السعودي — موقع العبايات

موقع عربي متجاوب مبني باستخدام **HTML وCSS وJavaScript وBootstrap RTL** فقط، دون إطار عمل أو عملية بناء. هذه نسخة ثابتة قابلة للرفع إلى مستودع GitHub أو إلى استضافة صفحات ثابتة.

## الملفات

- `index.html`: الصفحة الرئيسية ومحتواها العربي.
- `styles.css`: تنسيق الموقع المتجاوب.
- `script.js`: بطاقات الموديلات وأسعارها وأزرار التواصل عبر واتساب.
- `public/brand/logo.png`: شعار البيت السعودي بصيغة PNG.
- `public/products/`: صور الموديلات العشرة.

## المعاينة على الجهاز

افتح `index.html` في المتصفح. إذا لم تظهر الصور عند فتح الملف مباشرة، شغّل خادمًا محليًا من مجلد المشروع باستخدام `python3 -m http.server 8000` ثم افتح `http://localhost:8000`.

يتطلب تحميل Bootstrap RTL وخط Cairo اتصالًا بالإنترنت. جميع صور الشعار والمنتجات محفوظة داخل مجلد `public`.

## التواصل عبر واتساب

تنتقل أزرار الاستفسار عن المنتجات إلى محادثة واتساب على الرقم `01223358691`.

## رفع الملفات إلى GitHub

أنشئ مستودعًا جديدًا في حسابك، ثم اختر رفع الملفات وأضف محتويات هذه الحزمة مع الحفاظ على المجلدات كما هي، وبعدها احفظ التغييرات. اجعل `index.html` في جذر المستودع.

لإضافة العميل إلى مستودع خاص، أضفه كمساهم من إعدادات المستودع؛ أما الرابط العام فيتطلب ضبط ظهور المستودع كعام، وهذا يجعل الشيفرة متاحة للجميع.
